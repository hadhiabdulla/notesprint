# Visual walkthrough

1. Landing: intended learner is a student with intermittent internet or a shared phone. Show the offline status and no-account/no-note-upload scope. A first visit still requires a connection.
2. Tap Try a made-up example, then Make practice cards. Explain the two explicit note formats. The heading without a separator is reported, not converted into a guessed question.
3. Review and edit a prompt. Answers are copied from the supplied notes, not fact-checked. This prototype runs rules, not a language model.
4. Start a round. Try an answer, reveal, and mark Needs another look. Mark remaining cards as recalled. Summary says self-ratings, not mastery. Revisit shows only the missed card.
5. Save the deck file. Remembering is off by default for shared-device privacy. If showing opt-in, turn it off or clear afterwards. Clear does not delete downloaded files.
6. Demonstrate verified offline reopening after initial caching, not merely an "offline" badge. A browser can evict app data; keep a deck backup.
7. Larger text/phone layout and keyboard controls. State which actual checks were run and which devices remain untested.

Contribution disclosure: AI-assisted design, implementation, tests, docs and synthetic examples. No pre-existing project foundation, external runtime libraries or learner dataset. No claim of improved learning outcomes. Video optional under AccessED rules; screenshots + working demo can document this flow.
